# cry_console
O Cry Console é uma plataforma onde gestores de e-commerce podem conectar o GA4, o Clarity, o Google Console e a VTEX (por enquanto) para obter insights de negócios. Essa é a camada inicial; além disso, a plataforma contará com recursos de observabilidade e agentes projetados para estruturar estratégias comerciais, de SEO e de CRO.
